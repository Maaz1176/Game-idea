# Brackeys Platformer — Double Jump Edition

Open with Godot 4.3 or later: extract the archive, Import `project.godot`, then press F5. Allow the initial asset import to finish.

Move with A/D or arrows. Press and release Space, then press it again in midair to double jump. Landing restores both jumps. Walking off an edge leaves one air jump. Press R to restart.

The added HUD shows jumps remaining and coins collected. Cyan tint marks the air jump.

Read **Changes.txt** for the assignment explanation and exact player-script diff. The added code is also marked in `scripts/player.gd`; all of `scripts/jump_hud.gd` is new.

This extends the official finished project for [Brackeys' beginner tutorial](https://www.youtube.com/watch?v=LOhfqjmasi0), using its original platformer level and assets.
